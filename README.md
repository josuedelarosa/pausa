# Pausa — demo de bienestar

**Demo publicado en ChatGPT Pages:** [Pausa](https://pausa-bienestar.josuedelarosa.chatgpt.site/)

Escanea este código QR para abrir la plataforma:

[![Código QR para abrir Pausa](assets/qr-pausa.svg)](https://pausa-bienestar.josuedelarosa.chatgpt.site/)

Prototipo académico de una página web estática para reflexionar sobre el bienestar emocional. El formulario y su orientación funcionan localmente en el navegador.

## Abrir localmente

Abre `index.html` en un navegador. No requiere instalar dependencias ni configurar un servidor.

## Publicar con GitHub Pages

1. Crea un repositorio en GitHub.
2. Sube `index.html` y este `README.md` a la rama principal.
3. En **Settings → Pages**, elige desplegar desde la rama principal y la carpeta raíz.
4. Guarda los cambios y espera a que GitHub Pages publique el sitio.

## Alcance del prototipo

- La devolución es una simulación con reglas locales; no usa un modelo de IA conectado.
- Las preguntas y los perfiles son una simulación educativa, no una prueba clínica validada ni un diagnóstico.
- Las respuestas no se envían ni se guardan en un servidor.
- La sección de planes es ilustrativa: no hay registro ni procesamiento de pagos.
- La devolución compara 36 parejas entre las nueve respuestas principales mediante reglas explícitas y descriptivas.

Consulta [el análisis del algoritmo y de todas las combinaciones](ANALISIS-ALGORITMO.md) para conocer sus reglas, límites y el cálculo del espacio de respuestas.

Antes de convertirlo en un servicio real, habría que validar el cuestionario, definir avisos de privacidad y consentimiento, y evaluar los requisitos aplicables al uso previsto.
